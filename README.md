# SIPTrace

Настольная и браузерная САПР электроники: схемы, платы, библиотеки УГО и корпусов, ГОСТ/ЕСКД, ERC/DRC, CAM и 3D-просмотр.

Исправление 1.1.2: ЛКМ в пустом месте снимает выбор объектов и подсветку цепей; контуры фигур проверяются по видимым линиям. Перекрёстный выбор между окнами не пересылается обратно и не отменяет локальный сброс выделения. Смена инструмента отменяет незавершённое перетаскивание.

Исправление 1.1.1: панорамирование зажатой средней кнопкой мыши выполняется без поиска контактов под курсором; камера обновляется не чаще одного раза за кадр. Подавлена встроенная автопрокрутка WebView2 и устранена повторная рассылка выбора компонента при движении мыши.

## Запуск и проверка

```powershell
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run test:e2e
```

Браузерные тесты используют Microsoft Edge. По умолчанию `test:e2e` запускает Vite с исходным кодом на порту 4173. Чтобы проверить production-сборку, выполните `npm run build`, затем `$env:SIPTRACE_E2E_PREVIEW = '1'; npm run test:e2e`. Предпросмотр сборки использует порт 4174. При импорте внешних форматов учитывайте предупреждения приложения.

### Сравнение схем с DipTrace

В каждой папке с эталонами положите `схема.dch` и снимки тёмного окна DipTrace `схема_sheet_1.png`, `схема_sheet_2.png` и так далее. Номера соответствуют порядку вкладок. Для этих снимков в DipTrace использован масштаб по содержимому (Home).

```powershell
$env:SIPTRACE_DIPTRACE_REFERENCES = "$env:USERPROFILE\Downloads\SCHEMES"
$env:PLAYWRIGHT_HTML_OUTPUT_DIR = 'playwright-report/diptrace'
npx playwright test diptrace-visual --output test-results/diptrace --reporter=list,html
npx playwright show-report playwright-report/diptrace
```

Тест открывает каждый `.dch` через редактор, снимает рабочую область и сопоставляет проводники после выравнивания по масштабу и смещению. Проверяются длинные линии на эталоне и проводники на снимке SIPTrace. Дополнительный кадр допускается, если его рабочая область совпадает с последним листом с учётом выделения. В HTML-отчёте сохраняются оба снимка и карта различий. Зелёным показаны совпадения, красным — участки эталона без совпадения, синим — участки SIPTrace без совпадения. Надписи, цвета компонентов и оформление ГОСТ можно сверить на приложенных снимках.

## Сборка Windows

Требуются Rust, MSVC Build Tools и Windows SDK, WebView2 и Node.js.

```powershell
npm run build:exe
```

Результат: `release/SIPTrace.exe`, копия с номером версии и файлы SHA-256. Настольная версия использует ту же production-сборку интерфейса. Бинарные файлы и каталоги сборки не хранятся в Git.

## Схемотехника 1.1

ПКМ и Esc отменяют активную операцию и возвращают обычный курсор. В Select контакт подсвечивается при наведении; ЛКМ на контакте начинает провод. СКМ перемещает вид, колесо масштабирует вокруг курсора. В Select ПКМ открывает меню объекта. Shift добавляет/исключает объекты из выбора, рамка слева направо выбирает содержащиеся объекты, справа налево — пересекаемые.

Рамка, Ctrl+A, перенос, удаление, копирование и вставка работают с компонентами, проводами, узлами, портами, шинами и графикой. По умолчанию перенос и преобразования сохраняют подключённые связи. Alt при переносе позволяет отделить выбранный объект от проводников. Перенос является одной операцией Undo; предварительное движение не сохраняет каждый кадр в документ.

| Команда | По умолчанию |
|---|---|
| Провод / шина / порт | W / B / P |
| Компонент / текст / окружность | A / T / O |
| Узел / отвод шины / не подключать | J / Q / N |
| Поворот / отражение | R или Space / X / Y |
| Переключить колено провода | Space во время рисования |
| Завершить провод / убрать последнюю точку | Enter / Backspace |
| Свойства / свойства по двойному щелчку | E / двойной щелчок |
| Выделить / вырезать / копировать / вставить / дублировать | Ctrl+A / Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+D |
| Сдвиг / увеличенный сдвиг | Стрелки / Shift+стрелки |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Сохранить / сохранить как / печать | Ctrl+S / Ctrl+Shift+S / Ctrl+P |
| Поиск / показать лист / масштаб | Ctrl+F / Home / + и − |
| ERC / передать в плату | F9 / Ctrl+B |

Вставка сначала показывает фрагмент на курсоре. R/X/Y преобразуют превью, ЛКМ фиксирует его, ПКМ/Esc отменяют. В свойствах доступны координаты, подписи, посадочное место, текст, таблицы и интерфейсы иерархических блоков. «Листы...» управляет порядком, именами, копиями и удалением листов. Двойной щелчок по иерархическому блоку открывает дочерний лист. Для подключения сигнала шины используйте отвод рядом с концом провода и задайте имя сигнала.

Пользовательские сочетания задаются через «Инструменты → Настройка горячих клавиш»; конфликты не позволяют сохранить назначение. Буквенные команды поддерживают физические клавиши при русской раскладке.

Локальное автосохранение и запись файла — разные операции; их статус показан внизу редактора. Ошибка локальной записи сохраняет документ в памяти и предлагает записать файл. Предыдущая локальная копия сохраняется в текущей браузерной сессии; при повреждении документа доступна выгрузка исходных данных и восстановление.

SVG и печать используют общие функции отрисовки; печатный документ содержит только листы в физическом размере, без интерфейса, выделения и сетки. Поля системного диалога печати и масштаб принтера следует проверять перед печатью.

Исторический аудит и сопоставление исправлений находятся в `audit/`. Изменения проверяются unit-тестами электрической связности, браузерными сценариями и сравнением эталонного Canvas-скриншота.
