# Аудит схемотехники SIPTrace — 16.11.2026

Проверена версия репозитория `a6efc9a`. Цель текущего этапа — выявить проблемы перед переработкой редактора. Функциональные исходники не изменялись. Добавлены этот отчёт, воспроизводящий сценарии скрипт и результаты его запуска.

Проверка: чтение обработчиков мыши, клавиатуры, состояния документа, Canvas, меню и свойств; запуск 17 браузерных сценариев и блока проверок движков в отдельном временном профиле Edge через Playwright. Браузерные пробы выполнялись на Vite dev с React StrictMode. Особенности StrictMode явно отмечены; работа нативного окна Tauri, печать на физическом принтере и производительность больших реальных схем не проверялись.

Это список обнаруженных проблем и функциональных пробелов, а не утверждение об отсутствии иных дефектов. Предложения UX отмечены отдельно от воспроизведённых ошибок. Прошедшие ранее 30 unit- и 12 e2e-тестов не покрывают большинство приведённых жестов редактирования.

## Что выяснено по замечаниям пользователя

| Замечание | Результат проверки |
|---|---|
| Нет нужных шорткатов | Частично: W/B/P, R/X/Y, Undo/Redo и другие уже существуют. Не хватает команд для обычного редактирования; `+` действительно не работает, настройка сочетаний неполная. |
| ПКМ не возвращает обычный курсор | Подтверждено. ПКМ начинает панорамирование или сохраняет набранный провод; активный инструмент остаётся. |
| Нельзя начать провод из подсвеченного пина в Select | Подтверждено. Нет состояния наведённого контакта, его подсветки и такого перехода в рисование. |
| Выделенные объекты перемещаются не все | Подтверждено. Рамка выбирает только компоненты; смешанной группы нет. |
| Узлы пересечений не перемещаются | Подтверждено. Перенос компонентов не обновляет junctions, а ветвь с узлом может остаться на месте. |
| Провода не удаляются Delete | Уточнение: непосредственно выбранный одиночный провод удаляется. Провода внутри рамки не выбираются, поэтому Delete их не затрагивает. При фокусе в поле ввода редактор намеренно не перехватывает Delete. |
| Надписи не вращаются с объектом | Подтверждено для RefDes и номинала: их смещения заданы в мировых координатах и не преобразуются вместе с символом. Удобного независимого редактирования надписей также нет. |

## Очерёдность улучшений

1. **Целостность операций и соединений.** Единая модель selection и электрических точек; исправление лишнего удаления через ПКМ, завершения drag вне canvas, перемещения узлов/ветвей/портов; согласованные rotate/flip/align. Номера 05–06, 09–15, 17–22.
2. **Обычная работа мышью.** ПКМ/Esc → предсказуемая отмена, подсветка пина, провод из Select, редактирование сегментов, подвижные подписи, структурный copy/paste. Номера 01–04, 07–08, 16–20, 26–27.
3. **Команды и клавиатура.** Единый реестр команд вместо отдельных обработчиков меню/toolbar/keydown; Ctrl+A/X/D, свойства, сдвиг стрелками, рабочий +, настройка без конфликтов. Номера 23–25, 45.
4. **Документ и модель.** Локальные/глобальные цепи, многосекционные корпуса, классы цепей, стабильные определения компонентов, история и сохранение. Номера 28–43.
5. **Доведение оформления.** Полные свойства и листы, таблицы, печать/SVG, регрессии взаимодействий. Номера 44–52.

Расширять декоративные функции до исправления соединений нецелесообразно: редактор должен сохранять электрический смысл схемы при обычных действиях пользователя.

## Критерии приёмки первой итерации

- ПКМ/Esc предсказуемо прекращают операцию; контекстное меню закрывается Esc и не меняет посторонние объекты.
- В Select ближайший контакт подсвечивается; клик на нём начинает провод, а завершение на другом контакте/проводе/порту фиксирует именно показанную связь.
- Рамка и Ctrl+A выбирают все поддерживаемые типы; Delete/Cut/Copy/Move работают по одной модели выбора.
- Перенос связанного фрагмента сохраняет внутренний netlist, узлы и ответвления. Внешние связи обрабатываются по явно выбранному режиму Move/Drag.
- Rotate/Flip применяют согласованное преобразование к объектам, проводам, портам и позициям подписей; текст остаётся управляемым и читаемым.
- После одного завершённого действия одна отмена восстанавливает документ полностью, включая topology и dirty; Redo возвращает тот же результат.
- Отпускание мыши вне холста, потеря фокуса и смена листа не оставляют активный drag или чужой черновик.
- Ошибка сохранения видна пользователю; автосохранение и запись файла различаются.

## Воспроизведение

Из корня проекта запустить `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`, затем `node audit/schematic-ux-probe.cjs`.

Скрипт использует искусственную схему с двумя компонентами, проводом между ними, ветвью, узлом, портом GND, текстом и шиной. Каждая браузерная проба загружает исходную схему заново. Профиль временный; сохранённые документы пользователя и его открытое приложение не затрагиваются. Движковые пробы используют копии схемы. Скрипт фиксирует наблюдения и контрольный положительный сценарий Delete; это ещё не набор регрессионных assertions для будущих исправлений.
