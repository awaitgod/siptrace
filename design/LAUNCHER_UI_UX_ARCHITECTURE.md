### Выявленные проблемы:
1. **Пространственный коллапс (Space Inefficiency):**
   - Контейнер ограничен жестким `max-width: 1232px` с `margin: auto`. На современных рабочих станциях инженеров (1920×1080, 2560×1440, 4K) более **70% площади экрана** представляет собой абсолютно пустое мертвое поле.
   - Рабочая область по вертикали заполнена лишь на 25%.
2. **Отсутствие визуальной и пространственной иерархии:**
   - Нет левого навигационного сайдбара. Пользователь не может переключиться на шаблоны ГОСТ, калькуляторы импеданса, базы компонентов, справочники ЕСКД.
   - Мелкая сжатая таблица без графических превью: проекты воспринимаются как безликий текст. Инженер вынужден вспоминать проект только по текстовой строке.
3. **Изолированный блок «Редакторы»:**
   - 5 кнопок редакторов справа оторваны от контекста проекта. Инженер открывает пустой редактор без привязки к активной плате или схеме.
4. **Отсутствие быстрого инспектора (Quick Inspector / Project Dossier):**
   - Невозможно оценить состав проекта (есть ли плата, готова ли схема, сформирован ли перечень элементов ПЭ3, проверен ли DRC/ERC), не открывая тяжелый редактор.
5. **Ограниченная фильтрация и поиск:**
   - Строка поиска ищет только по подстроке имени. Нет поиска по десигнаторам ГОСТ, применяемым микросхемам, тегам, статусам готовности.
6. **Отсутствие быстрых заметок инженера:**
   - В САПР критически важен контекст: на каком этапе трассировка, какие замечания нормоконтроля, какой зазор в дифпарах. Сейчас это негде записать.

## 3. Детальная спецификация блоков и интерфейсных зон

### 3.1. Левая навигационная панель (Left Navigation Sidebar)
- **Габариты:** фиксированная ширина `248px` (на экранах <1100px сворачивается в иконочный рельс `56px` или по горячей клавише `Ctrl + B`).
- **Брендинг и системный статус:**
  - Логотип DIPTR / SIPTrace с бейджем версии и статусом «ГОСТ ЕСКД Active».
- **Разделы навигации (Accordion / Flat Categories):**
  1. **Проекты (Projects Hub):**
     - «Все проекты» (со счетчиком общего числа).
     - «Закрепленные» (Pinned ⭐).
     - «В работе» (Active / In Progress ⚡).
     - «Архивные / Завершенные» (Archive 🗄️).
  2. **Шаблоны проектов (Templates & Standards):**
     - ЕСКД Форматы (А4 альбомная/книжная, А3, А2 с основной надписью по ГОСТ 2.104-2006).
     - Промышленные шаблоны (Двухсторонняя ПП 1.6мм, 4-слойная плата с полигонами питания, Микроконтроллерный модуль).
  3. **Библиотеки и компоненты (Libraries):**
     - Символы УГО (ГОСТ 2.702 / 2.710).
     - Посадочные места (IPC-7351B / ГОСТ 28836).
     - 3D STEP / VRML модели корпусов.
  4. **Инженерные инструменты (Engineering Tools):**
     - *Калькулятор печатных проводников:* расчет ширины дорожки по току (IPC-2152), расчет волнового сопротивления микрополосковых и дифференциальных линий (Microstrip / Stripline / Coplanar).
     - *Универсальный CAD-импорт:* DipTrace (.dch, .dip), Eagle (.sch, .brd), KiCad (.kicad_sch, .kicad_pcb), Altium (ASCII), Gerber/Excellon.
  5. **База знаний и нормоконтроль (Standards & Knowledge Base):**
     - Интерактивный справочник ЕСКД (ГОСТ 2.701, 2.702, 2.710-81, 2.104).
     - Таблица классов точности печатных плат (Классы 1–5 по ГОСТ 23751).
- **Нижний блок профиля и системных настроек (Sidebar Footer):**
  - Профиль инженера: «Иванов А.С. (АО НИИ Приборостроения)» — автоподстановка в штамп чертежа.
  - Кнопка вызова настроек (`Ctrl + ,`).
  - Переключатель темы оформления (Dark / Light / ЕСКД Высококонтрастная).

### 3.2. Центральная область (Main Hub)

#### 3.2.1. Верхний командный бар (Top Command Bar)
- **Умная поисковая строка (Smart Search Bar):**
  - Поддержка префиксных запросов:
    - `sch:` — поиск только по схемам;
    - `pcb:` — поиск только по платам;
    - `gost:` или `дес:` — фильтр по десигнаторам (например, `gost:468364`);
    - `comp:` — поиск проектов, использующих конкретную микросхему (например, `comp:STM32` или `comp:MAX485`);
    - `layer:4` — поиск 4-слойных плат.
  - Мгновенная очистка (`Esc`) и фокус по клавише `/`.
- **Группа действий первичного приоритета (Primary Action Group):**
  - Кнопка **«+ Создать проект»** (акцентный синий стиль, вызов `NewProjectDialog`, `Ctrl + N`).
  - Кнопка **«Открыть файл...»** (`Ctrl + O`, выбор `.dch`, `.dip`, `.json`, `.zip`).
  - Кнопка **«Импорт из CAD»** (выпадающее меню с форматами).
- **Панель переключения режимов отображения (View & Filter Controls):**
  - Чипсы быстрой фильтрации: `[Все (8)]`, `[⭐ Закрепленные (2)]`, `[⚡ В работе (3)]`, `[📐 ГОСТ ЕСКД (5)]`, `[🧪 Демо-проекты (2)]`.
  - Переключатель отображения: `[🔲 Сетка карточек (Grid)]` / `[📋 Таблица (Table)]`.
  - Сортировка: «По дате изменения», «По имени», «По десигнатору ГОСТ», «По сложности/слоям».

#### 3.2.2. Сетка карточек проектов (Project Grid View)
Каждая карточка спроектирована по принципу **«Инженерная информативность без перегруза»**:
- **Превью-контейнер (16:9 или 4:3):**
  - Четкий векторный рендер схемы или топологии платы на темном/светлом фоне.
  - В углу превью — плавающий бейдж типа: `[Э3 Схема]` или `[ПП Плата: 2 слоя, 90×55 мм]`.
  - Кнопка «⭐ Закрепить» в правом верхнем углу превью.
- **Информационный блок карточки:**
  - **Название проекта:** крупный четкий шрифт (14px semi-bold).
  - **Десигнатор ГОСТ:** отображение фирменным шрифтом `OpenGost` (например, `ГТРС.468364.001 Э3`).
  - **Инженерные бейджи-чипсы:**
    - `2L` (2 слоя) / `4L` (4 слоя)
    - `90×55 мм` (габариты контура)
    - `ERC: 0 ошибок` / `DRC: Готово`
    - `ГОСТ 2.104` (оформлен штамп)
  - **Временная метка и автор:** «Изменен: Сегодня, 14:20 • Иванов А.С.»
- **Всплывающий Toolbar быстрых действий (Hover Action Overlay):**
  - При наведении курсора появляются кнопки быстрого открытия:
    - Иконка «Открыть в Схеме» (`wire`);
    - Иконка «Открыть в Плате» (`toPcb`);
    - Иконка «3D Просмотр» (`view3d`);
    - Меню контекстных операций `...` (Дублировать, Экспорт zip, Удалить, Открыть в проводнике).

#### 3.2.3. Табличный режим (List View)
Для пользователей, работающих с десятками проектов:
- Колонки таблицы:
  1. ⭐ (Закрепить);
  2. Иконка типа проекта;
  3. Наименование изделия и десигнатор ГОСТ;
  4. Состав (иконки Sch, Pcb, 3D, Bom со статусом готовности);
  5. Характеристики (Слои, Габариты платы, Кол-во компонентов);
  6. Проверка (Статус ERC/DRC);
  7. Последнее изменение;
  8. Быстрые действия (кнопки открытия).

### 3.3. Правая панель «Инспектор проекта» (Project Dossier / Quick Inspector)

Панель открывается справа (ширина `360px–400px`) при выборе любой карточки или строки проекта:

1. **Мультимодальное интерактивное превью (Preview Deck):**
   - Переключатель режимов просмотра:
     - `[Схема Э3]` — векторная схема с возможностью панорамирования и зума колесиком мыши;
     - `[Топология ПП]` — дорожки, контактные площадки, полигоны, шелкография;
     - `[3D Модель]` — трехмерная сборка платы со всеми компонентами на Three.js.
2. **Паспорт и дерево состава проекта (Project Manifest Tree):**
   - Инженерное дерево файлов с индикаторами целостности:
     ```
     📁 ГТРС.468364.001 "Гальваническая развязка RS-485"
     ├── 📄 Схема электрическая принципиальная (Э3)
     │   └── RS485_Main.sch (Лист 1, Лист 2) — [ERC: Ошибок нет]
     ├── 🔲 Топология печатной платы (ПП)
     │   └── RS485_Layout.pcb (2 слоя, 90x55мм, 48 компонентов) — [DRC: OK]
     ├── 📊 Документация ЕСКД
     │   ├── Перечень элементов (ПЭ3) — [48 позиций сформировано]
     │   └── Спецификация (СП) — [ГОСТ 2.106-96]
     └── 🏭 Производственные файлы (CAM)
         ├── Gerber RS-274X (Top, Bottom, Mask, Silk)
         └── Excellon Drill (Сверловка: 32 отв., 4 диаметра)
     ```
3. **Кнопки моментального перехода в целевой редактор:**
   - Четыре крупные кнопки с иконками:
     - `[ В редактор схем ]` (открытие в SchematicModule)
     - `[ В редактор плат ]` (открытие в PcbModule)
     - `[ В 3D сборку ]` (открытие в Pcb3dModule)
     - `[ Экспорт Gerber / Спецификации ]` (прямой вызов генератора файлов)
4. **Инженерный блок заметок и задач (Project Engineering Scratchpad):**
   - Интерактивный Markdown-блокнот и список задач (TODO), привязанный к проекту:
     - Автосохранение при вводе;
     - Чекбоксы задач (например: `[x] Согласовать зазоры с технологом`, `[ ] Провести тепловой расчет драйвера`);
     - Быстрые заметки о ревизиях платы (Rev A -> Rev B).

- **Основной интерфейсный шрифт:** `Inter Variable` (размеры 11px, 12px, 13px, 14px, 16px, 20px) — идеальная читаемость в микротаблицах и UI-элементах.

## 5. Эргономика, клавиатурное управление и доступность (a11y)

### 5.1. Карта горячих клавиш (Keyboard Shortcuts Map)

| Сочетание клавиш | Контекст | Выполняемое действие |
|---|---|---|
| `Ctrl + N` | Глобально | Открыть диалог создания нового проекта (`NewProjectDialog`) |
| `Ctrl + O` | Глобально | Диалог открытия локального файла проекта |
| `Ctrl + I` | Глобально | Быстрый импорт сторонних CAD файлов |
| `/` или `Ctrl + F` | Глобально | Фокус в поле умного поиска `Smart Search` |
| `Esc` | Поиск / Инспектор | Сброс поиска, снятие выделения проекта, закрытие инспектора |
| `Стрелки ↑ / ↓ / ← / →` | Список / Сетка | Перемещение фокуса между проектами (с автопоказом в Инспекторе) |
| `Enter` | Выбранный проект | Открытие проекта в основном ассоциированном модуле |
| `Shift + Enter` | Выбранный проект | Открытие проекта сразу в трассировщике плат (`pcb`) |
| `Ctrl + 3` | Выбранный проект | Открытие проекта сразу в 3D просмотрщике (`pcb3d`) |
| `Ctrl + B` | Глобально | Свернуть / развернуть левую навигационную панель |
| `G` / `L` | Main Hub | Переключение вида: Grid (Сетка) / List (Таблица) |
| `Ctrl + Shift + T` | Глобально | Циклическое переключение тем (Тёмная -> Светлая -> ГОСТ) |
| `F1` или `?` | Глобально | Открыть оверлей горячих клавиш и справки |

### 5.2. Стандарты доступности (Accessibility & Usability)
- **Полная клавиатурная навигация (Keyboard Trap Prevention):** циклический фокус внутри модальных окон с восстановлением фокуса на вызывающий элемент при закрытии.
- **ARIA Семантика:**
  - Карточки проектов имеют атрибуты `role="article"` и `aria-selected="true/false"`;
  - Инспектор проекта помечен как `role="region" aria-label="Паспорт проекта"`;
  - Результаты живого поиска анонсируются через `aria-live="polite"`.
- **Контрастность:** соотношение контраста текста к фону не менее **5.5:1** для стандартного текста и **7:1** для чертежных надписей (соответствие стандарту WCAG 2.1 AAA).
