# UX Бенчмарк и концепция Start Hub / Launcher для САПР электроники DIPTR / SIPTrace

**Агент №2: UX Бенчмарк лучших стартовых экранов и лаунчеров в мире профессионального ПО**

## 1. Анализ лучших практик: деконструкция эталонов

### 1.1. JetBrains Welcome Screen (IntelliJ IDEA, CLion, PyCharm) — Золотой стандарт для профессионалов

Welcome Screen в линейке JetBrains считается эталоном эргономики для девелоперов и инженеров. 

#### Ключевые архитектурные паттерны JetBrains:
1. **Строгое разделение ответственности (Двухуровневая навигация):**
   - **Левая вертикальная панель:** верхний блок рабочих контекстов (`Projects`, `Remote Development`, `Customize`, `Plugins`, `Learn`). Нижний блок служебных элементов (Manage License, Help, Accounts).
   - **Центрально-правая зона:** полностью отдана под выбранный контекст.
2. **Фокус на быстрых действиях (Primary Action Bar):**
   - В правом верхнем углу списка проектов всегда закреплены 3 главные кнопки:
     - `New Project` (акцентная primary-кнопка);
     - `Open` (открытие существующего файла/каталога через системный диалог);
     - `Get from VCS / Clone` (клон из Git/GitHub/GitLab с валидацией URL прямо в диалоге).
3. **Организация и иерархия проектов:**
   - **Project Groups (Папки проектов):** группировка проектов по клиентам, устройствам или тематикам (например, `RS-485 Sensors`, `Power Supplies`, `Daughterboards`). Группы можно сворачивать, переименовывать, удалять без удаления файлов на диске.
   - **Pin to Top:** закрепление избранных проектов вверху списка (иконка булавки/звезды), предотвращающее вымывание активного проекта из списка недавних.
   - **Кастомные иконки и бейджи:** возможность назначить индивидуальную иконку или аватар проекту для мгновенной зрительной идентификации среди десятков строк.
   - **Продвинутое контекстное меню (Right-click):**
     - *Show in Explorer / Finder* (открытие папки в ОС);
     - *Open in Terminal / Shell*;
     - *Copy Path* (абсолютный путь в буфер обмена);
     - *Edit Project Tags / Color*;
     - *Remove from Recent Projects* (с подсказкой, что проект не удаляется с диска).
4. **Поиск и мгновенная фильтрация:**
   - Поле поиска с фокусом по горячей клавише `/` или `Ctrl+F`.
   - Живой поиск с подсветкой подстроки (highlighting).
   - Поиск работает не только по имени, но и по пути, названию ветки git и тегам.
   - Клавиатурная навигация: стрелки `↑` / `↓` переключают проекты, `Enter` открывает, `Delete` убирает из списка.
5. **Drag-and-Drop прямо в окно лаунчера:**
   - Перетаскивание файла (`.dip`, `.dch`, `.sch`, `.kicad_pcb` и др.) или папки проекта мгновенно открывает его в соответствующем модуле.

### 1.2. Blender Splash Screen — Визуальный фокус и шаблоны

Blender ориентирован на визуальное творчество и сложный пайплайн, поэтому его стартовый экран решает две задачи: **быстрый старт по пресетам** и **визуальное узнавание**.

#### Ключевые паттерны Blender:
1. **Шаблоны рабочего процесса (New File Presets):**
   - При старте пользователь выбирает не просто «новый файл», а специализированный шаблон:
     - *General* (универсальный 3D);
     - *2D Animation* (настроенный холст и кисти);
     - *Sculpting* (высокополигональная сфера и специализированный интерфейс);
     - *VFX* (трекинг камеры);
     - *Video Editing* (монтажный таймлайн).
   - **Для САПР электроники DIPTR:** аналог пресетов — *«Двухсторонняя плата (FR-4 1.6мм, JLCPCB)»*, *«4-слойная плата с BGA (контролируемый импеданс)»*, *«Схема по ГОСТ ЕСКД (А4/А3 рамка)»*, *«ВЧ/СВЧ трассировка (Rogers 4350B)»*, *«Библиотечный модуль»*.
2. **Визуальные превью (Visual Thumbnails):**
   - Последние файлы снабжены миниатюрами рендера сцены. В инженерном ПО это может быть скриншот топологии платы или принципиальной схемы.
3. **Моментальный доступ к ресурсам:**
   - Прямые ссылки на Release Notes, Руководство, Баг-трекер и Комьюнити.

### 1.3. Figma Home / File Browser — Пространство командной работы и гибкость отображения

Figma задает стандарты веб-нативных и десктопных рабочих сред с огромным количеством файлов.

#### Ключевые паттерны Figma:
1. **Гибридный просмотр: Grid View vs Detailed List View:**
   - **Grid (Карточки):** крупные карточки с визуальным превью содержимого, именем, автором и датой. Идеально для дизайнеров/инженеров, помнящих проект «в лицо».
   - **List (Таблица):** компактный список для плотного отображения десятков файлов с колонками (Название, Модифицирован, Создатель, Размер, Теги).
2. **Табы и быстрые выборки:**
   - `Recent` (Недавние), `Drafts` (Черновики/Песочница), `Pinned / Favorites` (Избранное), `Templates` (Шаблоны).
3. **Плавающие / Hover-действия:**
   - При наведении на карточку появляются кнопки быстрого действия: открыть в новой вкладке, скопировать ссылку, контекстное меню `...`.
4. **Левый сайдбар с переключением контекста:**
   - Рабочие пространства (Workspace), доступ к плагинам, библиотекам стилей и корзине.

## 3. Архитектура и UI-решения для центральной части (Main Canvas / Work Area)

### 3.1. Решение проблемы «пустоты и гигантских полей» на широких мониторах

#### Анализ текущей проблемы:
В существующем коде `LauncherModule.tsx` и `launcher.css` используется ограничение `max-width: 1232px; margin-inline: auto`. На современных мониторах 1440p (2560×1440) и 4K (3840×2160) более 50–65% полезной площади экрана превращается в мертвое пустое серое пространство, а таблица проектов зажата в узкий контейнер.

#### Предлагаемое решение: 3-колоночный адаптивный макет (Full-Width Adaptive Grid + Inspector)

```
+-------------------------------------------------------------------------------------------------------------+
| [Search Projects... (Ctrl+F)]       [Фильтры: Все | В работе | ГОСТ | Pinned]    [Новый проект] [Открыть...]  |
+-------------------------------------------------------------------+-----------------------------------------+
| ОСНОВНАЯ ЗОНА ПРОЕКТОВ (Резиновая сетка / Таблица)                | ИНСПЕКТОР ВЫБРАННОГО ПРОЕКТА (340-400px)|
| [Режимы: ⊞ Карточки | ☰ Список | ☷ Компактный]                    |                                         |
|                                                                   | +-------------------------------------+ |
| +---------------------+ +---------------------+ +---------------+ | | [Интерактивное превью платы/схемы]  | |
| | [Превью топологии]  | | [Превью топологии]  | | [...]           | | |                                     | |
| | STM32_Controller    | | RS485_Transceiver   | |                 | | | 85.0 × 54.0 мм  |  4 слоя (FR-4)    | |
| | Двухсторонняя       | | 4 слоя, ГОСТ ЕСКД   | |                 | | +-------------------------------------+ |
| | Обновлен: 2 часа наз| | Обновлен: вчера     | |                 | | Контроллер управления питанием        | |
| | [* Pin]      [PCB]  | | [* Pin]      [SCH]  | |                 | | Обозначение: АБВГ.468123.001 Э3       | |
| +---------------------+ +---------------------+ +---------------+ | | Путь: D:/Projects/PCB/PowerCtrl.dip   | |
|                                                                   | | Ветка Git: feature/rev2 (3 uncommited)| |
| +---------------------+ +---------------------+ +---------------+ | | Компонентов: 142 шт. (BOM готов)      | |
| | Power_Supply_12V    | | RF_Amplifier_2.4G   | |                 | | Статус DRC: 0 ошибок, 2 предупреждения| |
| | 2 слоя              | | Rogers 4350B, 50 Ом | |                 | | ------------------------------------- | |
| | Обновлен: 3 дня наз | | Обновлен: 5 дней наз| |                 | | [ Открыть Схему ]   [ Открыть Плату ] | |
| +---------------------+ +---------------------+ +---------------+ | | [ 3D Просмотр ]     [ Экспорт Gerber] | |
+-------------------------------------------------------------------+-----------------------------------------+
```

1. **Отказ от жесткого `max-width: 1232px`:** переходим на `width: 100%; padding: 24px 32px;` с адаптивной сеткой `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`. На 4K-мониторе будет элегантно отображаться 4–5 карточек в ряд, а на ноутбуке — 2–3 карточки.
2. **Правая панель инспектора (Quick Inspector / Project Preview):**
   - На мониторах шириной ≥ 1400px справа появляется панель подробностей выбранного проекта (как в macOS Finder / JetBrains / Figma).
   - Если проект выбран кликом (одинарный клик — выбор, двойной — открытие), в инспекторе отображается:
     * Крупное графическое превью (схема или плата);
     * Метаданные САПР: физические размеры платы (мм), количество слоев (1L, 2L, 4L, 6L), количество компонентов (BOM count), сетка и технологический класс;
     * Обозначение по ГОСТ (децимальный номер, наименование чертежа);
     * Быстрые кнопки запуска конкретного модуля: `[Схема]` `[Плата]` `[3D-вид]` `[Экспорт Gerber/BOM]`;
     * Статус проверки правил: `DRC: Clean` или `ERC: 2 warnings`;
     * Статус системы контроля версий (Git): текущая ветка, uncommitted changes.
   - На небольших экранах (< 1400px) инспектор автоматически сворачивается или открывается во всплывающем Drawer/Flyout.

### 3.2. Три режима отображения проектов (View Modes)

В верхней панели проектов располагается тумблер из трех кнопок:

#### 1. Режим «Карточки с превью» (Cards Grid) — по умолчанию:
- Карточка содержит:
  - Шапку с типом и иконкой первичного модуля (`Схема`, `Плата`, `Проект в сборе`);
  - Интерактивную или статическую векторную/растровую миниатюру платы или схемы;
  - Бейджи слоев и стандартов (`4 Слоя`, `ГОСТ`, `DRC OK`);
  - Название проекта жирным шрифтом и децимальный номер;
  - Относительное время изменения («2 часа назад», «Вчера, 18:40»);
  - Быструю кнопку пиннинга (звездочка/булавка в правом верхнем углу);
  - Наведение курсора (Hover): открывает быстрые кнопки `[Схема]` `[Плата]` `[3D]`, предотвращая лишние клики.

#### 2. Режим «Детальный список» (Detailed List Table):
- Идеально для опытных разработчиков, ведущих десятки проектов параллельно.
- Таблица с сортируемыми колонками:
  1. `Pin` (Избранное);
  2. `Название и децимальный номер` (с иконкой и подсветкой совпадений поиска);
  3. `Тип / Модули` (кликая на бейдж SCH/PCB/3D, пользователь сразу прыгает в нужный редактор);
  4. `Слои / Размеры` (например, `2L • 100×60 мм`);
  5. `Путь на диске / Репозиторий` (сокращенный путь с кнопкой «копировать»);
  6. `Дата изменения` (абсолютная и относительная);
  7. `Действия` (кнопка `⋮` контекстного меню).

#### 3. Режим «Компактный список» (Compact / JetBrains-style):
- Максимальная плотность информации (высота строки 32px): иконка, имя проекта, путь серым цветом справа, дата изменения. Позволяет видеть на экране 30–40 проектов без скролла.

### 3.3. Система быстрых фильтров и тегов

Над списком проектов размещается панель быстрых фильтров (Filter Pills / Chips):
- **[Все проекты]** (счетчик общего количества);
- **[В работе]** (проекты, измененные за последние 7 дней);
- **[★ Закрепленные]** (избранные проекты, всегда наверху);
- **[ГОСТ ЕСКД]** (проекты, содержащие спецификации, перечни элементов или схемы с штампами по ГОСТ);
- **[Многослойные (≥ 4 слоев)]** (сложные печатные платы с BGA/контролируемым импедансом);
- **[Шаблоны и демо]** (быстрый доступ к обучающим и демонстрационным платам: RS-485, MCU).

#### Пользовательские цветные теги (Tags):
Пользователь может через контекстное меню назначить проекту один или несколько цветных тегов:
- Тематика: `[Питание]`, `[Микроконтроллеры]`, `[СВЧ]`, `[Датчики]`;
- Статус: `[Прототип]`, `[В производстве]`, `[Тестирование]`, `[Архив]`.
Клик по любому тегу мгновенно фильтрует список.

## 4. Конкретный план трансформации текущей кодовой базы SIPTrace

### 4.1. Изменения в структуре компонентов (`src/ui/modules/launcher/`):
- `LauncherModule.tsx` декомпозируется на модульные компоненты:
  - `LauncherSidebar.tsx` — навигационный рельс (Проекты, Шаблоны, Модули, Библиотеки, Настройки, Инфо);
  - `LauncherHeaderBar.tsx` — глобальный поиск, фильтры-чипсы, переключатель вида (Cards/List/Compact), кнопки создания/открытия;
  - `ProjectGridView.tsx` — адаптивная сетка карточек с превью;
  - `ProjectListView.tsx` — табличное представление высокой плотности с сортировкой;
  - `ProjectInspector.tsx` — правая панель с подробными метаданными платы, схемотехникой, DRC-статусом и превью;
  - `ProjectContextMenu.tsx` — контекстное меню (Pin, Show in Explorer, Copy Path, Rename, Remove, Tags);
